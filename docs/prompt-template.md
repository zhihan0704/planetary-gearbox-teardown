# Teardown 风格 HTML 生成提示词模板

适合做交互式产品剖面、机械拆解和结构演示。复制下方整个提示词，把双花括号中的内容换成你的需求。未确定的可选项写「默认」。可以把[参考截图](preview.png)和提示词一起发给 AI，帮助它复现布局与配色。

## 可复制提示词

```text
制作一个 Teardown 风格的交互式 HTML 页面。让观众看清对象的结构，通过操作理解它的工作原理。

【项目输入】
展示对象与页面标题 = {{例如：手摇磨豆机 / 手冲研磨机构}}
一句话简介 = {{用一句话解释它做什么、怎么做}}
讲解重点 = {{希望观众记住的一个原理，或想看清的一段动作}}
可检查部件 = {{按操作或拆解顺序列出 3–6 项，每项填写名称 / 功能 / 选中后要看清的细节}}
标签和数据 = {{状态、读数、单位、固定规格、比例或公式 / 无数据填“无”}}
参考素材 = {{可选：参考 HTML、外观图、剖面图、尺寸，标明各自参考什么}}
页面语言 = {{默认：简体中文}}
交互模式 = {{默认：可旋转 3D＋逐件拆解＋全拆；也可指定 3D 热点或 2D 交互剖面}}
自动导览 = {{默认：开启；约 20–30 秒一轮，闲置 25 秒恢复}}

【版式】
以 1600 × 900 为桌面构图参考，页面随视窗缩放。顶部是通栏眉栏，左侧为小型几何标记和短名称，中间为对象分类，右侧放复位和导览控件，底部用一根 1px 细线收边。

主体采用左窄、中宽、右窄三栏。参考列宽 1 : 3.45 : 1.08，外边距约 3.25vw，栏间距约 2.2vw。
• 左栏上部放小型类别标签、紧凑的两行大标题和一句简介，下部用分割线排列 2–3 项读数。数值放大，单位缩小。数据缺失时使用有依据的实用参数或精简读数区。
• 中栏是唯一的视觉主体。给模型一块浅色展台，四角用短直线定位，左上角显示当前部件或状态，底部保留简短操作提示。默认装配态约占视窗高度的 65–75%，全拆态适当拉远并重新居中，四周留出足够余量。
• 右栏用有细分割线的部件列表。每行是编号、名称、简短功能标签和右侧斜箭头。选中项用淡暖底色和 3px 锈橙左线。列表下方放深色的「全部拆解／重新装配」按钮，底部显示当前部件名称与一到两句工作原理。
• 底栏左侧展示少量需要比较的关键规格，右侧展示导览状态和细进度条。工具提示、编号和标签服务于导航、状态或理解。

【视觉】
使用暖白纸面 #F2F0EB、炭黑 #242521、辅助文字 #5C5C54、分割线 #CBC8BE。锈橙 #D75A33 用于小标记、选中线和进度，深锈橙 #A43E24 用于强调文字。状态选中底色用 #E9DFD4。页面以直角、细线和留白为主，整体像一本可以操作的设备手册。

拉丁字标题用 Instrument Sans 650 左右字重，桌面字号参考 clamp(47px, 4.38vw, 84px)，两行间距紧凑。中文标题用清晰的中文无衬线，保持自然字距。参数、编号和状态用 IBM Plex Mono 或系统等宽字体，数字启用等宽排列。小标签拉开字距，说明文字保持舒展的行距和明显的层级。

展示区从 #FDFBF6 向 #E7E4DC 做轻微径向渐变，叠一层约 42px 间距、7% 不透明度的细网格，中心淡出。模型用柔和的棚拍光、轻接触阴影和能读出结构的材质分区。机械对象可用冷灰金属与暖色内件。将细节用在连接处、剖面和运动关系上，保持背景克制。

【交互】
初始显示装配态，3D 模式使用正交相机和略俯视的三分之四视角。点击部件时，视角、部件位置、列表选中态和说明同步更新。动作约 0.9–1.3 秒，先让挡住视线的部件退开，再沿装配轴分层移出目标件。热点或 2D 模式沿用相同的选中反馈，按输入选择合适的视图过渡。

3D 视图支持拖拽旋转、缩放、键盘操作和复位。全拆后能重新装配。实时读数和部件运动共用同一状态。可在运行状态下独立暂停机构运动。开启导览时，用同一组交互状态依次演示装配、单个部件、全拆和回到装配。桌面端可用轻量的演示光标指向实际按钮，光标不拦截点击，用户接管后立即隐藏。显式暂停保持到用户重新播放。尊重系统减少动态效果的设置。

【响应式与交付】
窄屏（约 760px 以下）改为「简介和数据 → 展示区 → 部件列表与说明 → 页脚」。展示区可近似正方形，3D 镜头按实际容器重新取景。部件列表可用两列，按钮适合触控。保留可见键盘焦点，控件提供正确的名称和选中状态。

交付一个完整的 .html 文件。默认双击即可离线使用，将 CSS、JS 和必要资源打包到文件内。使用 3D 时可用 Three.js，优先复用几何并内联打包依赖。体积以约 1 MB 为目标。无法确认的运行参数可留空，有演示值时明确标为示意。

交付前用 1600 × 900 和 390px 宽度检查页面，点击所有部件按钮，测试所选模式下的视图操作、复位和导览切换。检查初始态及各关键状态有无裁切，控制台有无错误，断网后能否打开。
```

## 填写示例

只需把模板中的「项目输入」换成下面这一段，就能用同样的版式做另一件展品。

```text
展示对象与页面标题 = 手摇磨豆机 / 一颗豆子的研磨路径
一句话简介 = 摇动手柄，让咖啡豆经过磨芯并落入粉仓。
讲解重点 = 从调节环入手，看清两片磨件之间的间隙如何改变。
可检查部件 = 手柄 / 输入转动 / 观察与中心轴的连接
             磨芯 / 研磨咖啡豆 / 观察内外磨件的相对位置
             调节环 / 改变研磨间隙 / 观察调节前后的剖面
             粉仓 / 收集咖啡粉 / 观察从主体拆下的方向
标签和数据 = 只显示有依据的规格，演示用粗细档位标为示意
参考素材 = 默认
页面语言 = 简体中文
交互模式 = 可旋转 3D＋逐件拆解＋全拆
自动导览 = 开启
```
